## 🌟 Возможности проекта

1. **Генератор FFB-профилей (DCS World & War Thunder)**
   * Поддержка всех основных летательных аппаратов: современные истребители (`F-15C`, `F-15E`, `Su-35`, `Su-27`, `F-22A`, `FA-18C`, `F-16C`, `MiG-29`), вертолеты (`UH-1H`, `Ми-8`, `Ми-24`, `Ка-50`, `AH-64D`), поршневые Warbirds (`P-51D Mustang`, `Spitfire`, `Bf 109`, `Fw 190`, `Як-52`) и автоматическая классификация любых кастомных модулей.
   * **Физический расчет аэродинамических усилий**: кривая скоростного напора ($Q \propto V^2$), учет обдува винтом на стоянке, трансзвукового скачка плотности потока (Mach stiffening), АРУ и переходного режима косой обдувки вертолетов (ETL).
   * **Двухрежимный интерактивный график**: переключение между скоростным напором ($0 — V_{max}$ км/ч) и механической S-кривой хода ручки ($-100\% — +100\%$) с четким околонулевым упором (*Detent* $\pm 2.97\%$).
   * **Стили пилотирования**:
     * 🔴 **Хардкор**: 100% сил базы, максимальный реализм отдачи и вибраций.
     * 🟡 **Казуал**: 50% усилий, мягкие тактильные эффекты без усталости рук.
     * 🟢 **Пилотажник**: минимальные усилия (уровень баз VPC MongoosT-50 ~2.0 кг) с полным отключением вибраций на ручке для ювелирного прицеливания.
   * **Чеклист 28 физических эффектов** FFBeast Commander: центрирование, скоростной напор, обдув, угол атаки, перегрузка G, Smart Damper, триммирование, срыв потока, флаттер, форсаж, стрельба пушки, касание ВПП, замки шасси, сход вооружения.

2. **Интерактивный 3D/2D Конфигуратор механики FFBeast**
   * Выбор ревизии базы (V5 редуктор 3:1, V4 редуктор 3:1, Direct Drive 1:1).
   * Расчет крутящего момента моторов (30 мм, 25 мм, 20 мм гироскутерные моторы, MiGE сервомоторы) с учетом длины кронштейна (+0 мм, +75 мм, +100 мм, +200 мм) и проверка запаса прочности по току.

3. **Светлый современный авиационный дизайн**
   * Премиальная светлая палитра (Aviation White & Sky Blue), вдохновленная приборными панелями и профессиональными симуляторами.
   * Адаптивная верстка (десктоп, планшет, мобильные устройства).

## 🚀 Быстрый старт локально

```bash
# Клонировать репозиторий
git clone https://github.com/mercooler666/apache_ffbeast_7734.git
cd apache_ffbeast_7734/web

# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev

# Собрать production-билд
npm run build
```

Приложение будет доступно по адресу `http://localhost:5173/`.

## 📦 Развертывание на GitHub Pages

В репозитории настроен автоматический CI/CD воркфлоу [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

При каждом `push` в ветку `main` проект автоматически собирается через Vite и деплоится на GitHub Pages:
1. Перейдите в **Settings $\to$ Pages** в вашем репозитории на GitHub.
2. В секции **Source** выберите **GitHub Actions**.
3. Сайт станет доступен по ссылке: `https://mercooler666.github.io/apache_ffbeast_7734/`.

---

## 🕹️ Как использовать сгенерированные файлы профилей

1. В конфигураторе выберите самолет, параметры вашей базы и стиль полета.
2. Нажмите **«Сгенерировать профиль»** и затем **«Скачать .JSON»**.
3. Скопируйте полученный файл в папку программы управления FFBeast:
   ```text
   FFBeast Commander/effect_profiles/
   ```
4. В приложении FFBeast Commander выберите ваш модуль и нажмите **Load Profile**.
